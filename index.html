Frequently Asked Questions

What is a Discord timestamp? +

A Discord timestamp is a special message tag like <t:1790958030:F> that Discord renders as a date and time in each reader's own time zone. Everyone in a server sees the same moment, converted to their local time automatically.

How do I use a Discord timestamp? +

Pick a date and time above, click any format to copy its code, then paste it into a Discord message. Discord replaces the code with the formatted time when the message is sent.

What do the letters in a Discord timestamp mean? +

The letter after the second colon picks the display style: t and T for times, d and D for dates, f and F for date and time together, and R for a relative time like "in 3 hours". Leaving the letter off uses the default f style.

What is the number in a Discord timestamp? +

It's a Unix timestamp: the number of seconds since January 1, 1970 UTC. This generator calculates it for you from the date and time you choose.

Do Discord timestamps work in every time zone? +

Yes. That's their main purpose. Each person sees the time in the time zone set on their own device, so you never have to convert event times by hand.

Do Discord timestamps work in embeds, bots and nicknames? +

They work in regular messages, embed descriptions and fields, and bot messages. They do not render in usernames, nicknames, channel names or embed titles.
